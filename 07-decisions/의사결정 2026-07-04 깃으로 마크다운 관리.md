# 의사결정 2026-07-04 깃으로 마크다운 관리

## Context

이 시스템은 개발 노트, TODO, 일간 목표, 회고, 그래프 보기, 데스크톱 사용, 모바일 열람을 지원해야 한다.

## Decision

마크다운 파일을 원본으로 두고 Git으로 관리한다. Obsidian은 그래프, Canvas, Bases, 백링크, 모바일 접근을 위한 인터페이스로 사용한다.

## Consequences

- 볼트는 특정 SaaS에 묶이지 않는다.
- Git 이력은 명확하게 확인할 수 있다.
- `.base`, `.canvas`처럼 지식 구조를 설명하는 Obsidian 파일은 추적할 수 있다.
- 모바일 Git 흐름은 단순하게 유지하고, 중요한 Git 작업은 데스크톱에서 처리한다.
