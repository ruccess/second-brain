# Second Brain

This vault is a Git-managed Markdown second brain.

## Principle

- Markdown files are the source of truth.
- Git keeps history.
- Obsidian is the desktop/mobile interface.
- Links, tags, and properties make the graph useful.
- Bases provide database-like views without turning notes into a SaaS silo.

## Daily Flow

1. Open [[HOME]].
2. Capture rough thoughts in `00-inbox/`.
3. Write today's note in `01-daily/`.
4. Convert useful ideas into `02-dev-notes/`, `03-projects/`, or `07-decisions/`.
5. Commit changes with Git.

## Core Note Types

- Daily note: today, goals, TODO, short reflection.
- Dev note: technical knowledge, errors, patterns, snippets.
- Project note: ongoing work, status, next actions.
- Area note: long-running responsibility or theme.
- Decision note: why a technical choice was made.
- MOC: map of content for navigation and graph shape.
