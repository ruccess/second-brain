# Git-managed Markdown

Git-managed Markdown means the note files are the durable source of truth.

## Why

- Plain text is portable.
- Git gives history and rollback.
- Editors can change later without losing the archive.

## Practice

- Keep notes small and link them with `[[wikilinks]]`.
- Use properties for structured views in [[HOME]] and Bases.
- Use commits as checkpoints, not as a perfect diary.
